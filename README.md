# Dias Tleugabylov — Designer Portfolio
**Author:** Dias Tleugabylov  
**Topic:** Designer portfolio — work, services, and contact.  
**Technologies:** HTML5 and CSS3.
## Links
- [Repository](https://github.com/tleugabylov-dias/landing-tleugabylov)
- [Website](https://tleugabylov-dias.github.io/landing-tleugabylov/)
## Website sections

- **Home:** an introduction and a link to the selected projects.
- **Work:** two practice projects, TOCHKA and FORMA, with expandable descriptions.
- **About:** a short introduction and design interests.
- **Services:** brand identity, web design, and graphic design.
- **Contact:** a contact form and a link to the GitHub profile.

The navigation menu uses anchor links to move between sections on the same page.
## Features
- Semantic HTML elements: `header`, `nav`, `main`, `section`, `article`, and `footer`.
- One main `h1` heading, `h2` section headings, and `h3` project and service headings.
- Contact form with name, email, and message fields.
- Associated `label` elements and `required` attributes for all form fields.
- An email field using `type="email"`.
- Descriptive `alt` text for images.
- Page title, meta description, viewport settings, and a custom favicon.
- Responsive CSS with layouts for mobile and desktop screens.
- Visible keyboard focus and a skip-to-content link.
- Reduced-motion support for users who prefer less animation.
- Expandable project descriptions using `details` and `summary`.
The website uses no JavaScript, CSS frameworks, or ready-made templates. Images and styles are stored locally.
## Project structure
```text
index.html
styles.css
favicon.svg
README.md
assets/
  chrome-study.jpg
  tochka-coffee.jpg
```
- `index.html` contains the page content and structure.
- `styles.css` contains the layout, colors, typography, and responsive rules.
- `favicon.svg` is the browser tab icon.
- `assets` contains the project images.
## Notes
TOCHKA and FORMA are practice concepts rather than commissioned client projects. The project was developed with AI assistance, including the chrome and coffee packaging images.

The contact form is a demo and does not send messages. Its submit button is disabled because a form-processing service has not been connected.
## Local preview
Open `index.html` in a browser. Keep `styles.css`, `favicon.svg`, and the `assets` folder in the same project directory.
## Hosting

The project is prepared for GitHub Pages using the `main` branch and the repository root (`/`). After enabling Pages, check that the website link above opens correctly.
